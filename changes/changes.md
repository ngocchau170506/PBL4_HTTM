# [CHANGES] BỘ QUẢN LÝ LỖI, THÍ NGHIỆM VÀ PHIẾU YÊU CẦU

- BUG-TEMPLATE.md: mẫu hồ sơ bug (triệu chứng, nodePath, nguyên nhân gốc). Mỗi bug một file `BUG-<số>.md`.
- CR-TEMPLATE.md: mẫu Change Request (đổi hợp đồng, scope hoặc luật). Mỗi CR một file `CR-<số>.md`. CR-001.md đang PROPOSED.
- EXP-TEMPLATE.md: mẫu hồ sơ thí nghiệm hiệu năng. Mỗi thí nghiệm một file `EXP-<số>.md` (CLAUDE.md mục 10).
- EXPERIMENT-LOG.md: sổ tổng các thí nghiệm và trạng thái.
- LOG.md: nhật ký bàn giao từng lần merge.
- BUG-xxx.md, CR-xxx.md: file giữ chỗ cũ, để trống.
