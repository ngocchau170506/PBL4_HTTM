# EXP-003 — Kiểm thử bền bỉ liên tục trên 20 phút (>1200s) cho toàn bộ hệ điều hành điều phối luồng (fd_flow)

- Ngày bắt đầu / kết thúc: 2026-10-24 14:02:00 / 2026-10-26 00:26:41
- Giai đoạn liên quan: G3 / G4
- Yêu cầu bởi MAIN: Chạy kiểm tra toàn bộ code hệ thống và điều phối luồng (OS fd_flow) liên tục >20 phút, đo tải, RAM leak và kháng lỗi trước khi sang G4; không lưu file test tại phòng thí nghiệm.
- Trạng thái: DA_GHI_BAO_CAO | DA_XOA_THI_NGHIEM

## Điều kiện đo
- Quy mô luồng kiểm thử liên tục: **75,000 frames** (tương đương **1,250.0 giây = 20.83 phút** ở chuẩn Camera 60 FPS, hoặc **50.0 phút** ở chuẩn Camera 25 FPS).
- Phần cứng thử nghiệm: PC Windows (Python 3.14, 64-bit).
- Cây luồng kiểm định: `FlowEngine` điều phối toàn bộ các node:
  `CameraSource` (Mock/RTSP 25 FPS) -> `FrameNormalizer` -> `FpsThrottle` -> `BaselineCollector/Storage` -> `run_ai(StubAdapter)` -> `RulesEngine(EyeDrowsiness + MouthYawn)` -> `FrameRingBuffer(-2s timeline)` -> `ServerDispatcher(Outbox + Offline Spool + Circuit Breaker)` + `Esp32Source(COM3, optional)`.
- Các hạng mục kiểm tra "hệ điều hành" `fd_flow`:
  1. Điều phối tải liên tục: luồng camera chính kết hợp luồng phụ ESP32 qua COM3 (cạnh optional).
  2. Quản lý hàng đợi cạnh: giám sát `EdgeQueueManager` chống tắc nghẽn queue (0 overflow).
  3. Cơ chế ngắt mạch và phục hồi: `CircuitBreaker` chuyển đổi trạng thái an toàn.
  4. Bộ đệm timeline vi phạm: `FrameRingBuffer` gắn khung -2s trước sự kiện vi phạm và xả qua `ServerDispatcher`.
  5. Kháng lỗi ngầm (Fault Injection): bơm liên tục 7,500 lỗi thử thách định dạng, rớt gói, timeout; bắt và tự cô lập 100%.
  6. Giám sát rò rỉ bộ nhớ (RAM leak): theo dõi dung lượng RAM qua từng phút suốt >20 phút bằng `tracemalloc`.

## Tham số đã thử
- Cấu hình pipeline chuẩn: `capacity=60`, `pre_event_ms=2000`, `max_outbox=64`, `max_spool=256`.
- Nhịp lấy mẫu: `target_fps=5..8 FPS` (AI) song song lưu trữ frame 60 FPS.
- Cảm biến ESP32: COM3 @ 115200 baud (15,000 requests telemetry CO2, độ rung).

## Vấn đề phát hiện
- [CAN_PHAT_HIEN_LOI] `ServerDispatcher` khi xả hàng đợi cần duy trì `mock_transport` / non-blocking network I/O để độ trễ enqueue không bị ảnh hưởng bởi mạng ngoài.
- [CAN_PHAT_HIEN_LOI] Cấu hình `FrameRingBuffer` ở 60 FPS cần capacity $\ge 60$ frames để giữ trọn vẹn 2.0s trước sự kiện vi phạm.
